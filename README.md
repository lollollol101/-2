Название: "Всё для еды"
Краткое описание проекта: консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", масштабировать порции и генерировать список покупок. 

Запуск кода:
from main import Ingredient, Recipe, ShoppingList
Создание ингредиента:
ингредиент = Ingredient("название",  количество, "единицы измерения")
Создание рецепта с добавлением ингредиента:
рецепт = Recipe("название рецепта")
рецепт.add_ingredient(ингредиент)
Изменение количества порций:
рецепт для n = пицца.scale(n)
Создание списка покупок
список = ShoppingList()
список.add_recipe(рецепт, количество)

Запуск тестов:
pytest test_recipes.py -v

Установка:
```bash
git clone https://github.com/lollollol101/-2.git
cd <папка>
pip install -r requirements.txt
pytest
```
